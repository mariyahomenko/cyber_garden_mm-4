# CyberDoc — AI-ассистент по научным PDF

**CyberDoc** — это настольное приложение на Python и PyQt5 для глубокой работы с научными статьями в формате PDF. Программа извлекает текст (включая распознавание сканов), выполняет поиск, генерирует ответы с помощью LLM (DeepSeek или GigaChat), связывает факты со страницами документа и открывает PDF с подсветкой найденных фрагментов.

## Основные возможности

- **Умный поиск и ответы:** Генерация ответов на основе контекста статьи с указанием конкретных страниц.
- **Два LLM-провайдера:** Поддержка DeepSeek и GigaChat (с полноценной OAuth-авторизацией).
- **Работа с PDF:** Поддержка двухколоночной верстки, OCR для сканированных страниц (через Tesseract), поиск по точной фразе, словам или регулярным выражениям.
- **Формулы и цитаты:** Рендеринг LaTeX-формул, интерактивные ссылки на источники и якорные цитаты с подсветкой в PDF.
- **Научные данные:** Модуль извлечения структурированных данных (PCE, Voc, Jsc, FF для солнечных элементов; Recall@k, MRR, NDCG для RAG) с экспортом в JSON.
- **Безопасность:** API-ключи не хранятся в коде или настройках. Они вводятся в защищенное поле при первом запросе и живут только в памяти процесса.

## Установка и запуск

1. **Клонируйте репозиторий и создайте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # Linux/macOS: source .venv/bin/activate

2. **Установите зависимости:**
python -m pip install -r requirements.txt

2. **Запустите приложение:**
python main.py

**Примечание для OCR:** Для распознавания сканированных страниц рекомендуется установить движок Tesseract OCR с языковыми пакетами rus и eng. Приложение сначала использует pytesseract, а при его отсутствии — встроенный OCR-мост PyMuPDF. Без OCR сканы остаются доступными для просмотра, но поиск по ним и копирование текста работать не будут.

**Структура проекта**
- main.py — точка входа в приложение.
- cyberdoc/app.py — инициализация QApplication, темы и жизненный цикл.
- cyberdoc/ui/main_window.py — главное окно, библиотека PDF, история ответов и выбор провайдера.
- cyberdoc/ui/pdf_viewer.py — просмотр PDF, масштабирование, поиск, закладки и выделение областей.
- cyberdoc/pdfdoc.py — парсинг PDF, сортировка колонок, OCR и координаты подсветки.
- cyberdoc/client.py — HTTP-клиенты (DeepSeek, GigaChat), обработка ошибок и повторные попытки.
- cyberdoc/research.py — извлечение и валидация структурированных научных данных.
- cyberdoc/renderer.py — рендеринг HTML-ответов, формул и ссылок.
- cyberdoc/export_utils.py — экспорт паспорта и наборов данных в JSON.
- cyberdoc/theme.py — темная и светлая темы оформления.
- tests/ — модульные тесты (запускаются через pytest).

**Авторизация и безопасность**
Исходный код не содержит API-ключей, Client Secret или access-токенов.
- При первом «умном» поиске приложение запрашивает ключ через защищенный диалог.
- Ключи хранятся исключительно в оперативной памяти текущего процесса.
- QSettings сохраняет только выбранного провайдера, геометрию окна и пути к открытым файлам. Credentials туда не попадают.
- При закрытии главного окна все ключи, Client ID и OAuth-токены очищаются.

**Особенности провайдеров:**
- DeepSeek: Использует стандартный Authorization: Bearer <key> и потоковый ответ (stream).
- GigaChat: Использует OAuth 2.0 (Client ID + Authorization key → Basic-заголовок → запрос access token). Поддерживаются оба формата времени жизни токена (expires_at в epoch ms и ISO 8601). Токен кэшируется в памяти и сбрасывается при получении HTTP 401.
- 
**Переменные окружения (безопасные настройки):**
Вы можете переопределить URL и модели без изменения кода:
- DEEPSEEK_API_URL, DEEPSEEK_MODEL
- GIGACHAT_API_URL, GIGACHAT_OAUTH_URL, GIGACHAT_SCOPE
- GIGACHAT_VERIFY_SSL=1 (для строгой проверки SSL-сертификата)

**Работа с PDF и форматами**
- Двухколоночная верстка: Блоки текста сортируются по координатам (левая колонка → центр → правая колонка).
- Поиск: Поддерживает точную фразу, отдельные слова, вхождение в слова и регулярные выражения. Результаты сохраняются с координатами для подсветки.
- Формат ответа: Модель возвращает формулы в маркерах [[FORMULA ...]], а цитаты для навигации — в [[REF ...]]. Рендерер превращает это в HTML, а клик по ссылке открывает нужную страницу PDF и подсвечивает координаты.

**Внешние зависимости**
Для работы сетевых функций требуется доступ к API выбранного провайдера. Для OCR — установленный Tesseract. Все библиотеки Python (PyQt5, PyMuPDF, requests, Pillow, matplotlib) устанавливаются из requirements.txt.
